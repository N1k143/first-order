# Пилот разбора публичных страниц 2ГИС

`tools/dgis_pages.py` — самостоятельный ограниченный инструмент без API-ключа и дополнительных Python-зависимостей. Он разбирает HTML поиска и карточек Астаны, сохраняет локальный JSON и не записывает данные в рабочую базу. Интерфейс сайта не меняется.

## Запуск

Из корня проекта, Python 3.10+:

```sh
python3 backend/tools/dgis_pages.py --fetch --query 'Кафе' --limit 3 \
  --output /tmp/2gis-pilot.json
```

Сеть используется только при явном `--fetch`: robots.txt, одна страница поиска и максимум 10 карточек. Проверки идут последовательно с паузой не менее 3 секунд и учётом Crawl-delay. Разрешены только HTTPS-страницы поиска/карточек Астаны на `2gis.kz`. Редиректы, ошибки доступа, CAPTCHA/нераспознанные страницы и запреты robots останавливают пилот; частичные результаты и причина сохраняются. Ротации IP, решения CAPTCHA, браузерных cookies и запросов к внутреннему API нет.

Без сети можно разобрать сохранённый HTML:

```sh
python3 backend/tools/dgis_pages.py --input /tmp/company.html \
  --url https://2gis.kz/astana/firm/70000001059048104 \
  --output /tmp/company-result.json
```

Без `--url` файл считается страницей поиска: возвращаются обнаруженные ссылки, карточки автоматически не загружаются. Файлы ответа ограничены 4 МиБ, результат создаётся с правами 0600 без перезаписи существующего файла. Не добавляйте HTML и выгрузки в Git.

## Что означает результат

У карточки сохраняются `source_url`, ID, название, доступные адрес/телефоны/email, ссылки на платформы и возможные сайты, время проверки и признаки распознанной/полной страницы. Категория может остаться null: классификация произвольных рубрик пока не реализована.

`website_listing`:

- `listed` — в контактах есть ссылка на возможный собственный сайт; работоспособность и принадлежность сайта ещё не проверены.
- `not_listed` — карточка распознана, HTML полный, видны контактные данные, ссылка на сайт не обнаружена.
- `unknown` — недостаточно данных, неполная страница либо неразобранная ссылка. В такие результаты нельзя записывать отсутствие сайта.

Для всех карточек `website_status=needs_review`. **Сайт не указан в 2ГИС — не означает, что сайта нет.** Instagram/WhatsApp и другие платформы не засчитываются как самостоятельный сайт. Поиск сайта за пределами карточки в этом пилоте не выполняется.

Парсер определяет собственную карточку по h1, ссылкам вкладок с её ID и адресу. Блок рекомендаций обрезается до извлечения контактов. Переходные ссылки `link.2gis.ru` декодируются только для ID текущей компании и не запрашиваются; чужая реклама не приписывается компании. Скрипты и скрытые элементы не интерпретируются. Изменение разметки может дать unknown или остановку; это не основание массово менять статусы компаний.

## Ограничение использования

[Условия сервисов 2ГИС](https://law.2gis.ru/rules/) содержат ограничения автоматических запросов и выгрузки. У Казахстана есть [отдельное лицензионное соглашение](https://law.2gis.kz/licensing-agreement/). Доступность страницы и разрешающий путь в [robots.txt](https://2gis.kz/robots.txt) не заменяют разрешение на массовое извлечение, хранение и публикацию базы.

Прототип не подключён к регулярному сбору и не публикует карточки. Перед таким использованием необходимо определить разрешённые условия работы с данными. Пилот не переносит на данные 2ГИС лицензию ODbL источника OSM.
