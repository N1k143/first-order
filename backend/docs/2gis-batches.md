# Повторяемые поисковые партии 2ГИС

`backend/tools/dgis_batch.py` расширяет [HTML-пилот](2gis-pilot.md): несколько запросов Астаны, общая локальная база, прогресс/продолжение, кеш, ручные решения и выгрузка. Используются Python 3.10+ на Linux/macOS и стандартные библиотеки (файловая блокировка через fcntl). Фронтенд и production PostgreSQL не меняются. Сбор остаётся ограниченным ручным экспериментом с публичными страницами.

## Создать и продолжить

Из корня репозитория:

```sh
python3 backend/tools/dgis_batch.py start \
  --query 'Кафе' --query 'Салоны красоты' --query 'Автосервисы' --limit 9
```

По умолчанию SQLite находится в исключённой из Git папке `.ops/2gis.sqlite`. Можно явно задать `--state /закрытая/папка/state.sqlite` **перед** командой. Файлы базы/блокировки и выгрузки имеют закрытые права. Чужая SQLite-база или ссылка на файл не принимаются как состояние сборщика.

От одного до пяти разных поисковых запросов, от одной до десяти карточек **суммарно за задание**. Загружается только первая публичная страница каждой выдачи, до десяти ссылок из неё. Карточки выбираются по очереди из запросов, а не только из первого. Пагинация, обход города целиком и расписание в этом инструменте не включены.

Ответ start содержит UUID задания, status, queries, limit, processed/total, searches_completed, checked, cached, attempts, error. `position` дублирует processed для внутреннего формата. Во время получения выдач total ещё равен нулю. Задание не доказывает полноту покрытия ни города, ни категории.

```sh
python3 backend/tools/dgis_batch.py status --job UUID
python3 backend/tools/dgis_batch.py resume --job UUID
python3 backend/tools/dgis_batch.py history --job UUID
```

Состояния: pending/running/completed/paused/failed. Ctrl+C сохраняет уже завершённые контрольные точки и переводит задание в paused. После сбоя процесса ядро освобождает файловую блокировку; resume продолжает по сохранённому прогрессу. Выполненные выдачи и карточки заново не запрашиваются. Повтор completed не делает сетевых запросов. Не более трёх попыток на одно задание.

Один runner на файл состояния: параллельный запуск отклоняется. Просмотр прогресса, экспорт и ручные отметки доступны во время сетевых запросов. Результат карточки и сдвиг прогресса коммитятся одной SQLite-транзакцией; сеть выполняется вне неё. История событий хранит время и UID оператора ОС, без создания аккаунтов сервиса.

## Кеш, повторы и ошибки

Одинаковые ID 2ГИС объединяются между поисками. В карточке накапливаются discovery_queries. Разные ID филиалов не сливаются по одинаковому имени. Совпадение имени/телефона **вместе с адресом** даёт только подсказку possible_duplicate_ids (до десяти ID), а не автоматическое объединение.

Распознанная карточка кешируется на сутки по времени получения источника. В новом задании её повторное появление не вызывает новый запрос самой карточки; выдача всё равно запрашивается. Отмеченные dismiss/has_site не перечитываются автоматически даже при старом кеше. Импорт старого отчёта не заменяет более свежие исходные сведения.

Паузы robots.txt и сетевые ограничения наследуются от HTML-пилота. При ошибке запросов работа останавливается с сохранением прогресса. Общее ожидание в том же state-файле: 5 минут для обычной ошибки, час для 403/429/редиректа/нераспознанной страницы, сутки для ошибки robots. Создание другого задания в той же базе не снимает паузу. Автоматических повторов нет. Пустая/нераспознанная выдача требует ручной проверки и не трактуется как отсутствие компаний.

## Ручные решения

```sh
python3 backend/tools/dgis_batch.py review --id ID --decision keep \
  --notes 'Проверить наличие отдельного сайта'
python3 backend/tools/dgis_batch.py review --id ID --decision has_site \
  --website https://business.example.com --notes 'Ссылка найдена вручную'
python3 backend/tools/dgis_batch.py review --id ID --decision dismiss \
  --notes 'Не подходит для выборки'
```

unreviewed — исходное состояние; keep — оставить кандидатом; dismiss — исключить; has_site — оператор указал отдельный сайт. Это локальные отметки исследования, а не одобрение публикации и не подтверждение юридического владения сайтом. Они, комментарии и known_website сохраняются отдельно от исходных данных и не затираются сборщиком. Для возврата в обычную выборку используйте decision unreviewed.

## Выгрузки

```sh
python3 backend/tools/dgis_batch.py export --kind prospects --format csv \
  --output /tmp/2gis-prospects.csv
python3 backend/tools/dgis_batch.py export --kind all --format json \
  --output /tmp/2gis-companies.json
python3 backend/tools/dgis_batch.py export --kind unknown --format csv \
  --output /tmp/2gis-unknown.csv
```

Без --job выгружается накопленная база; с --job UUID — актуальные карточки среди обработанных в этом задании. Исторический исходный результат конкретной попытки остаётся в сохранённом состоянии задания; выгрузка учитывает текущие ручные решения. Существующие файлы не перезаписываются. CSV имеет UTF-8 BOM; значения с признаками формул, включая телефоны с плюсом, защищены префиксом апострофа для Excel. Длинные цифровые ID также защищены от округления Excel.

prospects включает только website_listing=not_listed, кроме dismiss/has_site. listed и unknown не попадают в целевую выборку. website_status остаётся needs_review: «в карточке не указан сайт» не означает «сайта нет». Сайты за пределами карточки автоматически не ищутся и не проверяются этим инструментом.

priority_score — прозрачная оценка полноты данных: 50 за not_listed, +20 за телефон, +15 за ссылки на платформы, +10 за email, +5 за адрес. Для остальных статусов/исключённых карточек — 0. Это порядок ручной проверки, а не вероятность покупки услуг. В CSV есть source_url, время источника, запросы обнаружения и возможные дубли.

Предыдущий отчёт пилота можно добавить без новых сетевых запросов:

```sh
python3 backend/tools/dgis_batch.py import-report --input /tmp/2gis-pilot.json
```

Проверяются источник, ID/URL, статусы, признаки полноценной карточки и формат контактов/даты. Ограничение импорта — 4 МиБ и 100 карточек. Вся партия импорта атомарна.

## Проверенный прогон

В прогоне 26 ноября 2026 использованы три запроса: кафе, салоны красоты, автосервисы. Завершены девять карточек: восемь прочитаны из источника, одна взята из ранее импортированного кеша. Три имеют not_listed, шесть — listed. С первым пилотом накоплено 11 уникальных карточек и четыре кандидата not_listed. Выгрузки и state остаются в закрытой временной папке, вне Git.

Перед массовым извлечением/хранением/публикацией по-прежнему требуется определить допустимые условия работы с данными 2ГИС; ограничения и первоисточники приведены в [описании пилота](2gis-pilot.md). Эта версия не подключена к регулярному сбору или рабочему каталогу.
