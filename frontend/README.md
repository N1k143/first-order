# First Order

Учебная платформа для поиска компаний без сайта и первых заказов для веб-разработчиков.

## Запуск

```bash
npm install
npm run dev
```

Адрес сервера выводится в терминале. Production-сборка: `npm run build`, запуск сборки: `npm start`.

## Структура

```text
app/
  layout.tsx                 # Общий каркас, метаданные, шапка и подвал
  page.tsx                   # Маршрут /: сборка секций главной
  globals.css                # Переменные, базовые стили, общие классы
components/
  home/                      # Секции главной страницы
    hero-section.tsx         # Первый экран с изображением телефона
    overview-section.tsx     # Возможности платформы
    catalog-section.tsx      # Поиск и фильтр компаний (клиентский)
    company-row.tsx          # Строка и подробности организации
    workflow-section.tsx     # Порядок работы
    faq-section.tsx          # Частые вопросы
    closing-section.tsx      # Завершающий блок
  layout/                    # Общие шапка и подвал
  auth/                      # Кнопка входа и диалог (клиентский)
  ui/                        # Переиспользуемые элементы: Brand
styles/
  home.css                   # Секции главной и адаптивные правила
  layout.css                 # Шапка, логотип, подвал
  auth.css                   # Кнопка входа и диалог
data/companies.ts            # Демонстрационные организации
types/company.ts             # Тип Company
public/                      # Изображения, доступные по URL
```

## Правила организации

- `app` отвечает за маршруты и общий каркас. Содержимое страницы находится в `components/home`.
- Страница, шапка, подвал и статические секции — Server Components. `use client` установлен только в каталоге и кнопке входа, где используются React-состояние или браузерный dialog.
- Данные передаются каталогу через props. Для подключения API измените получение данных в `app/page.tsx`, сохранив тип `Company`.
- Поиск и выбранный город хранятся рядом с каталогом; отдельный глобальный store или custom hook пока не нужен.
- Компонент строки каталога использует нативный `details`; FAQ тоже работает без отдельного JavaScript.
- Стили подключаются один раз в `app/layout.tsx`: сначала `globals.css` с общими `.wrap`, `.button` и типографикой, затем стили разделов. Такой порядок сохраняет адаптивные переопределения. При добавлении сложных независимых экранов используйте CSS Modules для локальных стилей.
- Новую секцию главной добавляйте в `components/home` и подключайте в `app/page.tsx`. Общие элементы выносите в `components/ui`, когда они действительно переиспользуются.

## Текущее состояние

Каталог использует демонстрационные данные; фильтрация и раскрытие профилей работают локально. Реальная авторизация и API пока не подключены. Телефон на главной — обычное изображение `public/first-order-hero-v2.png`.
