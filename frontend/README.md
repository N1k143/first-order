# FirstOrder frontend

Next.js 16 · React 19 · TypeScript · CSS Modules. Локальный Golos Text и общие токены дизайна FirstOrder.

## Запуск

```sh
npm ci
cp .env.example .env.local
npm run dev -- --hostname 127.0.0.1 --port 3120
```

Откройте http://127.0.0.1:3120. Шрифты поставляются локально.

## Форматирование

Код хранится в многострочном виде. Prettier настроен на два пробела и ширину строки 100 символов.

```sh
npm run format
npm run format:check
```

Откройте папку `frontend` в VS Code и установите рекомендуемое расширение Prettier. В `.vscode/settings.json` включено форматирование при сохранении; `.editorconfig` задаёт отступы и окончания строк для других редакторов.

## Проверки

```sh
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
CHROME_PATH=/usr/bin/google-chrome npm run test:browser
```

Браузерные тесты запускают **production-сборку** на отдельном порту 3121. Сначала выполните `npm run build`. Если системного Chrome нет, установите Chromium командой `npx playwright install chromium` и запустите `npm run test:browser` без `CHROME_PATH`.

## Структура

- `src/app`: тонкие маршруты App Router, общий layout и страница 404.
- `src/components`: навигация, поля, состояния и диалоги подтверждения.
- `src/features`: главная, каталоги, авторизация, кабинеты, заказы и модерация.
- `src/lib/state`: демонстрационное состояние и правила переходов заказов/откликов.
- `src/lib/api`: клиент запросов, ошибки, отмена и тайм-ауты.
- `src/data`: исходные демонстрационные данные.
- `src/types`: модели предметной области.
- `tests`: транспорт, правила заказов и браузерные сценарии.
- `tools/figma-export`: экспортёр макетов, не часть приложения.

## Данные и сервер

По умолчанию `NEXT_PUBLIC_DATA_MODE=demo`: действия сохраняются в localStorage этого браузера. Пароли не сохраняются; письма и приглашения не отправляются. В настройках можно переключаться между демонстрациями разработчика и компании, открыть модерацию или сбросить данные.

`BACKEND_URL` доступен только серверу Next.js. `/api/:path*` проксируется на этот адрес. Единственный реализованный Go-маршрут — `GET /health`, который возвращает `OK`. Проверка связи доступна в настройках.

`NEXT_PUBLIC_DATA_MODE=api` — заготовка для интеграции, **не рабочий режим текущего бэкенда**. Каталоги запрашиваются с сервера без подмены примерами; личные разделы показывают, что API пока отсутствует. После изменения публичной переменной требуется перезапуск dev-сервера или новая production-сборка.

Предполагаемые маршруты и ограничения описаны в `docs/backend-integration.md`. Бэкенд в этой работе не изменяется.
