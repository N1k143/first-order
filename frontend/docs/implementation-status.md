# Состояние FirstOrder

Источник дизайна: https://www.figma.com/design/eEBIHk6nceh158jZmZxCPe/FirstOrder

После лимита Figma MCP пользователь предоставил экспорты Desktop (36 экранов), Mobile (12 экранов) и UI kit в PNG/SVG. Интерфейс использует общие цвета, шрифт Golos Text, карточки, поля и навигацию макетов. Изображения экранов не используются вместо интерфейса.

## Страницы и сценарии

| Раздел             | Маршруты и поведение                                                                                                                             |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Главная            | `/`, поиск компаний, свежий открытый заказ из текущего состояния                                                                                 |
| Компании           | `/companies`, фильтры и поиск в URL, пагинация; `/companies/:id`, контакты, заметки и сообщения об ошибках                                       |
| Заказы             | `/orders`, фильтры; `/orders/:id`, описание именно выбранной задачи; `/orders/:id/apply`, один активный отклик                                   |
| Авторизация        | `/register`, `/register/developer`, `/register/company`, `/login`, `/forgot-password`, `/reset-password`, `/verify-email`                        |
| Разработчик        | `/dashboard`, `/applications` с отзывом предложения, `/saved`, `/contacts`                                                                       |
| Профиль            | `/profile`, `/profile/edit`, `/profile/portfolio`, сохранение профиля и добавление/удаление работ                                                |
| Настройки          | `/settings`, email демопрофиля, смена роли, сброс примеров, выход, проверка связи с сервером                                                     |
| Компания           | `/workspace`, `/workspace/orders`, `/workspace/profile`, `/workspace/members`, `/workspace/applications`                                         |
| Создание заказа    | `/workspace/orders/new`, сохранение черновика, `/workspace/orders/:id/edit`, `/preview`, публикация                                              |
| Управление заказом | `/workspace/orders/:id`, `/applications`, выбор исполнителя, отклонение остальных предложений и завершение заказа                                |
| Модерация          | `/moderation`, проверка обращений с обязательным основанием; `/moderation/history`, журнал; `/moderation/import`, состояние недоступного импорта |
| Информация         | `/about`, `/support`, `/privacy`, `/terms`                                                                                                       |

## Границы реализации

- Все изменения аккаунтов и заказов пока демонстрационные, сохраняются в браузере. Об этом сообщает интерфейс.
- В API-режиме не показывается фиктивный авторизованный профиль. Ошибки запросов не подменяются демонстрационными данными.
- Сервер реализует только `/health`. Приглашения, импорт, настоящая регистрация, пароль и email требуют серверной реализации.
- Модерация сохраняет решение по обращению и журнал, но автоматически не переписывает данные компаний.
- Публичный просмотр чужих профилей и контактные данные исполнителя требуют серверного контракта. `/profile` показывает текущий демопрофиль.
- Нативное поле даты и сообщение о деморежиме намеренно отличаются от статичного макета.
- Backend не изменён.

## Качество кода

Prettier, EditorConfig и настройки VS Code обеспечивают многострочное форматирование. `npm run format:check` проверяет оформление. ESLint и TypeScript проверяют исходники. Unit-тесты покрывают транспорт и переходы статусов; Playwright — публикацию, отклики, профиль, поиск, навигацию и мобильную ширину.
