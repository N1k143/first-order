# Состояние переноса FirstOrder

Источник: https://www.figma.com/design/eEBIHk6nceh158jZmZxCPe/FirstOrder

## Полученные материалы

- Главная, узел `8:2`: полный design context и скриншот. Шрифт Golos Text, локальная поставка через Fontsource.
- Desktop, страница `0:1`: структура узлов, без полного набора стилей.
- Mobile: получен пользовательский экспорт 12 экранов PNG/SVG.
- UI kit: получен пользовательский экспорт PNG/SVG.
- Desktop: получен пользовательский экспорт 36 экранов PNG/SVG.

Figma MCP остановил дальнейшее чтение из-за лимита Starter. Пользователь выбрал подготовку способа экспорта. Экспорт получен; перенос остальных страниц продолжается по PNG/SVG.

## Реализовано

Next.js App Router, TypeScript, CSS Modules и общие токены; главная со ссылками на будущие маршруты; общие шапка/подвал; переиспользуемая карточка заказа; API-клиент с ошибками, отменой и тайм-аутом; frontend proxy для существующего Go API.

## Ограничения текущего этапа

- Добавлены каталоги компаний и заказов, карточки компаний, контакты и исправления, страницы заказа и отклика, выбор роли, регистрация, вход и восстановление доступа. Поиск компаний и фильтры сохраняются в URL.
- Профили, кабинеты, настройки и модерация ещё не реализованы; ссылки на эти маршруты возвращают 404. Это промежуточный результат, не законченный продукт.
- По умолчанию используется демонстрационное состояние в localStorage. `NEXT_PUBLIC_DATA_MODE=api` включает запросы к предлагаемым API; это ещё не полноценная интеграция с авторизацией сервера. Пароли и email в демонстрационном режиме не обслуживаются сервером.
- Адаптация главной к мобильной ширине предварительная, до сверки с Mobile.
- Заказ на главной — пример из макета, а не данные API.
- Backend содержит только `GET /health`, отвечающий `OK`. CRUD, регистрация и сессии отсутствуют. Контракт будущих API не считается согласованным.
- Файлы backend не изменяются.

## Проверки и зависимости

Next.js обновлён с 16.4.1 до 16.4.6 после сообщения сборки об уязвимости. TypeScript, ESLint, 5 тестов транспорта и production-сборка проходят.

В dev-зависимостях `eslint-config-next` остаётся advisory для `picomatch` (GHSA-fc5q-39xc-vjpf); npm на дату проверки сообщает уязвимыми версии до 4.0.7 включительно, а актуальная версия — 4.0.7. Автоматическое предложение downgrade eslint-config-next не применено. Это инструмент разработки, не runtime-зависимость приложения.
